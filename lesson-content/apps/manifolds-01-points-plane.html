Step 1: A Manifold Is a Set of Points

No coordinates yet. Rotate a smooth surface in 3D and watch points appear and fade. The point-set is primary; coordinates are not yet introduced.

Questions:
We have below a plane (or sphere or saddle). In geometry we can call this a manifold.
This can be thought of as a smooth shape. These shapes have points, and that is all we assume for now.
Just a smooth shape with a set of points. No more or less. So here are some questions for you to think about:
How would you measure location?
How would you measure distance between points?
How would you measure angles?

Notes

Start with the shape only. Then press "Show Random Points" to reveal a changing subset of the manifold points.
